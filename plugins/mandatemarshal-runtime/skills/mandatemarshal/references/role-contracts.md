# Role Contracts

## Owner

Owns Owner Contracts, explicit exceptions, permanent policy, publication/licensing decisions, and materially irreversible changes.

## Parent

Owns request interpretation under Owner Contracts, architecture, task decomposition, semantic routing, complete implementation packets, actual candidate inspection, verification, review-loop handling, and final acceptance.

Parent may recommend an Owner-level option but may not execute it without approval.

## Implementer

Owns ordinary implementation detail inside the packet. Must report exact commands and evidence. Must stop the affected work when the packet conflicts with reality or higher authority.

## Fresh Reviewer

Fresh-context, read-only QA/code/execution-contract audit. It may detect bugs, regressions, edge cases, test gaps, scope violations, command/flag violations, artifacts, or material objective-bound risks.

It has no architecture or Owner-policy authority. Verdicts: `PASS | FIX | ESCALATE`.
